# 设计：从零开始 + 人才市场

> 2026-10-04 起草，**待用户确认后再写代码**。
>
> 用户要求（2026-10-04）：
> - 所有东西都从零开始建（诸侯一开始不拥有现成的城、人口、设施）。
> - 开局可以在网页设置：诸侯有多少**资金**、多少**粮食**；初始有多少**农民**、**伐木工**、**建筑工**。
> - 要建**人才市场**才能继续招兵买马，不再一开始就给那么多人口。
>
> 用户已拍板的选择：
> 1. 每个诸侯开局 **1 个空营地**，其余城址空着，之后用「建城」去占。
> 2. 开局设置**所有诸侯统一**（6 个起点一样，公平）。
> 3. 人才市场**花金和粮「招募」**；**自然出生关闭**。
> 4. 招士兵要 **人才市场 + 兵营**；其他职业只要人才市场。
> 5. 现有「12 城 + 2000 人」开局**直接替换**，不再保留（旧存档读不了，部分现有测试要改）。

## 1. 现在 → 之后

| | 现在 | 之后 |
|---|---|---|
| 城镇 | 12 座，每个诸侯 2 座，开局就有 | 每个诸侯 1 座**营地**（原都城的位置，没有任何建筑）；另外 6 个**空城址**无主，要「建城」才算数 |
| 人口 | 开局 2000 人，按比例分职业 | 按设置：每种职业开局几个人（默认 农夫 8、伐木工 4、建筑工 3，其余 0） |
| 增加人口 | 自然出生（吃饱、民心好就生）+ 房屋抬高上限 | **只能在人才市场「募」**；自然出生默认 0；房屋仍然抬高人口上限 |
| 资源 | 每城粮 400 / 木 150 / 石 80 / 铁 20 / 金 300 / 兵器 20 | 按设置：金、粮、木、石、铁、兵器（默认见 §3） |
| 田 | 开局城边有田 | **没有田**，农田建筑才有田（每座 6 块）；世界生成时撒在地图上的野田也去掉 |
| 名人 | 每个诸侯开局带 1 将军 + 1 谋士，另有 2 个在野 | 诸侯开局**不带名人**；2 个在野名人保留，可以用「招」招揽 |
| 士兵 | 比例里占 20%，开局就有 | 开局 0；要有人才市场 + 兵营才能募 |

## 2. 开局设置（网页「新世界」组，开新局时生效）

所有项都写在模块的 `config` 里，网页设置面板会**自动出现**，不用改前端。统一值（§1 的第 2 条）。

**资金与物资（每个诸侯的营地）**

| 设置 | 默认 | 范围 |
|---|---|---|
| 开局资金（金） | 200 | 0–100000 |
| 开局粮食 | 300 | 0–100000 |
| 开局木材 | 200 | 0–100000 |
| 开局石料 | 60 | 0–100000 |
| 开局铁 | 0 | 0–100000 |
| 开局兵器 | 0 | 0–100000 |

> 你只提了「资金、粮食」。**木材、石料我多加了**：没有木头连第一座房子、农田都建不了，开局会卡死。不想要的话把默认值设成 0 即可。

**各职业开局人数（每个诸侯）**

十种职业各一项：农夫、伐木工、石匠、矿工、建筑工、铁匠、搬运工、士兵、斥候、商人。默认 农夫 8、伐木工 4、建筑工 3，其余 0（士兵的人数设置可以填，**设置里直接给的不受「要建人才市场」限制**——限制只管开局之后的招募）。

**其他**

| 设置 | 默认 | 说明 |
|---|---|---|
| 营地人口上限 | 20 | 没房子时能住多少人；每座房屋 +30 |
| 每日自然出生率 | 0 | 原来的 `population.growth`，默认值从 0.004 改成 0；想开自己调 |
| 人才市场每日招募上限 | 5 | 每座人才市场每天最多招几个 |

名字保持：青龙的头 3 个人仍叫阿三、阿四、老王（命令例子里用到）。

## 3. 营地、空城址、建城

- **营地**：就是现在的「城镇」对象，`buildings = {}`、人口上限 = 「营地人口上限」。仓库 = 一份开局物资。
- **空城址**：每个诸侯原来的第 2 座城的位置。
  - 数据上仍是一个城镇对象，但标记 `founded = false`：不属于任何势力、没有人、没有仓库物资、不参与民心 / 吃饭 / 收税。
  - 地图上画成空心标记，鼠标点开显示「空城址：可建城」。
- **建城**（新命令）：`建城 <空城址名>`
  - 需要自己已经有至少一座城；可以建在任何空城址（不限定属于谁原来的）。
  - 材料：木 100、石 40，工作量 300（从最近己方城的仓库扣材料，建筑工去施工）。
  - 建成后：该城址 `founded = true`，归建城的诸侯，人口上限 = 营地人口上限，仓库为空；**没有人**，要靠人才市场募，或者搬运工 / 迁居送人去。
  - 可能被抢：城址上还没建好时，别的诸侯也可以派建筑工去同一个城址，先建成的人得城（后建的工地作废并退材料）。
- 已有的**攻城、占城**规则不变：已建成的城可以被攻下，易主。

## 4. 人才市场与「募」

**新建筑：人才市场（`talent`）**

- 建在城镇里，每城最多 1 座。
- 材料：木 80、金 50；工作量 200。
- 效果：本城可以用「募」招人。

**新命令：`募 <城镇> <职业>:<人数> …`**，例如 `募 青石城 农:3 木:2`

- 条件，任何一条不满足就**整条拒绝并说明原因**：
  1. 该城有人才市场；
  2. 今天该市场的招募额度够（默认每天 5 人，所有职业合计）；
  3. 招完后人口不超过上限（房屋 / 营地上限）；
  4. 仓库付得起费用；
  5. **士兵**另需该城有**兵营**。
- 费用 = 职业原有的培训费（`train.cost`，粮等）+ 新增的 `hire`（金）：

| 职业 | 金 | 原培训费 |
|---|---|---|
| 农夫 / 伐木工 / 石匠 / 建筑工 / 搬运工 | 10 | 粮 2–3 |
| 矿工 | 15 | 粮 4 |
| 铁匠 | 20 | 粮 5 |
| 斥候 | 25 | 粮 4 |
| 商人 | 30（含原来的 20） | 粮 4 |
| 士兵 | 30 | 粮 5、铁 1 |

  数字全部放在 `content/professions.ts` 里，改数据不用改代码。
- 人从哪来：凭空从「流民」里来，出现在城边，立刻属于这个城。**不设流民池**，不会因此少别人的人。
- 每个人才市场每天的额度用「当天已招人数」记，过一天清零（存档里要存）。

**没有人才市场时：**
- 现有的人仍然会按「比例」自动转职（付培训费），也可以用「转」命令。
- 人口只会因吃不饱、打仗、迁走而减少。不会增加。

## 6. AI 诸侯

- **提示词只给事实和数字**，不写「先造房子」之类的指令（规矩第 6 条）。简报新增的事实：
  - 人口 / 上限，今天已招 / 额度；
  - 本城有没有人才市场、兵营（有 / 无）；
  - 每种职业的招募单价（金、粮、铁）；
  - 空城址列表（名字、在哪个地区、离我最近的己方城多远）和建城材料。
- 命令表从 `CommandDef` 自动生成，不用手写。
- **脚本诸侯**（稳健 / 霸道 / 纵横）要重写开局逻辑，否则开局什么都不会干：按性格先建农田 → 房屋 → 人才市场 → 兵营，再募人、建城。脚本是测试用的策略，不是提示词，可以写具体顺序。
- 没有给 AI 加「秘密目标」之类的动机（要加会先问你）。

## 7. 测试怎么改

- **压测**（2000 人每拍 < 5 ms）：改成用「每职业人数」设置凑出 2000 人（营地人口上限相应调高），预算不变。
- **命令契约**（每个例子都能执行）：新命令「募」「建城」的例子要在测试开局下真的能跑；原有例子（如 `派 @木:5 伐木 北林`）依赖开局人数，**测试用的开局配置给足人数**，不靠默认值。
- **可重现、存档、脚本 AI 长跑**：换成新开局重写；脚本 AI 长跑要从零开始能发展起来（不饿死、能建人才市场、能募人）。
- **新增**：开局按设置生成（人数、物资正确，没有多余的人）、没有市场募不了、有市场 + 额度 / 上限 / 付不起 / 没兵营 各自被拒、建城成功和被抢建、自然出生为 0。
- 现有 83+5 项测试里，涉及「12 城 / 2000 人 / 河口镇」的都要改，改完全部要过才提交。

## 8. 分阶段交付（每阶段单独提交 + 推送）

1. **开局设置**：设置项、营地 + 空城址、按职业人数生成、开局物资、去野田和开局名人、存档版本；旧测试改到能过。
2. **人才市场**：建筑、「募」命令、额度、人口上限检查、关闭自然出生、兵营限制。
3. **建城**：命令、工地、被抢建、网页画空城址。
4. **AI**：简报事实、脚本诸侯重写、长跑测试。
5. **网页**：城镇面板的招募信息等。
